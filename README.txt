# AI-Based Traffic Vehicle Detection and Risk Assessment System

This project uses TensorFlow, SSD MobileNet, and OpenCV to detect vehicles, estimate speed, and calculate traffic risk scores.

## Features
- Vehicle Detection
- Vehicle Tracking
- Speed Estimation
- Risk Assessment
- Traffic Risk Visualization

## Technologies Used
- Python
- TensorFlow
- TensorFlow Hub
- OpenCV
- NumPy
- SciPy
